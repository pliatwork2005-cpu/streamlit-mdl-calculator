# streamlit-mdl-calculator
Gator MDL Data Calculation
save CSV data by clicking "Export Data" in the "Binding Fitting" tab of Gator data analysis. Do it for standard curves, and blanks.
open standard curves CSV (don't convert to excel files), delete row 1 content, add concentration number at B1, D1, F1..., save.
you can load multiple blank run curves.
